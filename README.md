# Village Guard — Fabric-мод для Minecraft 26.2

Жители-стражи с железным мечом и железной бронёй.

## Что умеют стражи
- Настоящая **модель жителя** (используется ванильный рендерер жителя), в руке виден железный меч.
- Экипировка: железный меч + полный железный комплект (броня работает по характеристикам, 40 HP, урон 7).
- **Защищают деревню**: атакуют любых монстров в радиусе (кроме криперов, чтобы не взрывали деревню).
- **Дают сдачи**: ударишь стража — он бьёт в ответ, а остальные стражи рядом приходят ему на помощь.
- Если ты бьёшь обычного жителя (или стража), стражи рядом тоже считают тебя целью (около 10 секунд после удара).
- **Появляются сами**: когда в мире появляется новый житель (генерация деревни, размножение, вылеченный зомби-житель), рядом с шансом 50% появляется страж. Лимит: ~1 страж на 3 жителя в радиусе 48 блоков, максимум 8.
- Не торгуют, не уходят далеко от деревни (радиус 32), медленно лечатся вне боя, не пропадают.

## Сборка
Нужны **JDK 25** и интернет (Gradle скачает Minecraft и Fabric).

```
gradle wrapper --gradle-version 9.5.1   # один раз, создаёт gradlew
./gradlew build                          # Windows: gradlew.bat build
```
Готовый мод: `build/libs/village-guard-1.0.0.jar` → положить в `mods/` вместе с **Fabric API** (26.2).

Нужен установленный Gradle 9.5+ только для создания wrapper (либо откройте папку в IntelliJ IDEA — она настроит всё сама).
Актуальные версии Loader / Loom / Fabric API смотрите на https://fabricmc.net/develop/ и правьте `gradle.properties`.

## Сборка без установки (GitHub)
1. Создайте пустой репозиторий на github.com и загрузите в него всё содержимое папки (включая `.github`).
2. Вкладка **Actions** → сборка запустится сама → внутри готовый артефакт `village-guard` (jar).
3. Если сборка красная, откройте лог и пришлите мне ошибки — исправлю.

## Проверка
- `/summon villageguard:village_guard` — призвать стража вручную.
- Создайте мир с деревней или найдите деревню — рядом с жителями появятся стражи.
- Ночью/`/summon zombie` рядом со стражем — он должен напасть.

## Важно: проект НЕ компилировался на моей стороне
Версия 26.2 очень новая, а у меня не было доступа к её исходникам/Maven, поэтому код написан по документации Fabric и именам Mojang без проверки компилятором. Места, где чаще всего нужны мелкие правки (имена/пакеты в 26.x менялись):
- `import ...npc.villager.Villager` — в 26.x класс лежит в этом пакете; если нет — IDE подскажет верный.
- `Identifier.fromNamespaceAndPath`, `LivingEntity#getLastHurtMob / getLastHurtMobTimestamp`, `Mob#restrictTo`.
- Лямбда `(target, level) -> ...` в `NearestAttackableTargetGoal` (сигнатура `TargetingConditions.Selector`).
- `EntityRenderers.register(..., context -> new VillagerRenderer(context))`.

## Известное ограничение
Броня **не видна визуально**: у модели жителя нет «человеческих» частей тела, поэтому ванильный слой брони на ней не рисуется (броня при этом реально действует). Видимую броню можно добавить отдельным слоем рендерера — скажите, и я доработаю.

## Почему мод, а не датапак
Датапак не может ни подменить модель сущности, ни научить жителя атаковать (у жителей в ваниле нет атакующего ИИ), ни надёжно ловить «ударили стража». Поэтому это мод.
